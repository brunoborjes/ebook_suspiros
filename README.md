📖 Suspiros — Landing Page de Alta Conversão

Uma landing page moderna, poética e responsiva desenvolvida para promover e vender o e-book de poesias "Suspiros", do autor Cleverson Borges.

🌸 Sobre o Projeto

A Suspiros é uma página de vendas projetada para transmitir a essência poética do livro através de uma experiência visual imersiva e de alta conversão. O design combina estética minimalista, paleta de cores galáxia/magenta extraída diretamente da obra original e microinterações leves.

✨ Principais Funcionalidades & Efeitos

Mockup 3D Interativo: Apresentação da capa oficial recortada em PNG transparente com sombra dinâmica (drop-shadow) e animação suave ao passar o mouse.

Efeito Dente-de-Leão (Partículas JS): Animação personalizada de sementes e pétalas flutuando sutilmente pela tela ao longo da navegação.

Efeito "Suspiro" no Menu: Interação delicada nos links de navegação com expansão de texto e bordas animadas no hover.

Cabeçalho Dinâmico (Glassmorphism): Menu com efeito de vidro fosco (backdrop-filter) que encolhe suavemente ao rolar a página.

Animação "Fade Up" na Rolagem: Revelação progressiva de seções utilizando IntersectionObserver para melhor desempenho.

Sticky CTA Flutuante: Barra inferior de compra rápida que surge automaticamente após a seção principal.

Accordion de FAQ: Pergunta e resposta interativo para quebra de objeções de compra.

Design 100% Responsivo: Adaptado minuciosamente para computadores, tablets e smartphones.

🛠️ Tecnologias Utilizadas

HTML5: Estrutura semântica focada em SEO e acessibilidade.

CSS3: Variáveis CSS (custom properties), Flexbox, CSS Grid, Animações (@keyframes), regras de media queries e manipulação de z-index e filtros visuais.

JavaScript (ES6+): Lógica interativa do FAQ, manipuladores de eventos de rolagem, animações por observador de interseção e sistema de partículas leves.

Google Fonts: Tipografias Cormorant Garamond (poética/serifada) e Plus Jakarta Sans (moderna/sans-serif).

🚀 Como Executar o Projeto Localmente

Clone este repositório:

cd suspiros-landing-page


Abra o arquivo index.html em qualquer navegador ou utilize a extensão Live Server no VS Code.
